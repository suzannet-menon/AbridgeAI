Seven agents, one run

Watch the preview above — this is the same sequence that runs in your browser.

  1. 01

    GitHub Agent

    Reads your public profile and top repos, or falls back to sample data if the API is unreachable.

  2. 02

    Research Agent

    A deterministic opportunity, risk, and direction scan for the idea as written.

  3. 03

    Feasibility Agent

    Scores the idea across five weighted axes and returns a GO, proceed-with-caution, or rethink verdict, an effort estimate, a four-phase plan, and a risk register.

  4. 04

    Architecture Agent

    A module breakdown and data-flow blueprint sized to the idea.

  5. 05

    Tech Stack Agent

    A stack recommendation — TypeScript, Python, Go, or Rust — matched to your comfort level.

  6. 06

    Builder Agent

    A starter file tree, starter files, and a milestone checklist — download it as a real, unzippable project.

  7. 07

    AO Task Agent

    Assembles one copyable, agent-ready task prompt citing the feasibility verdict and the scaffold.
